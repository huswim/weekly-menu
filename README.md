# Weekly Menu

병무청 사회복무연수센터 주간 식단표를 모바일에서 확인하는 정적 PWA입니다.

## 기능

- 날짜별 조식·중식·석식과 A/B 코너
- 오늘은 한국 시간에 맞는 식사 자동 선택, 다른 날짜는 전체 식단 표시
- 08:30까지 조식 / 08:31–13:30 중식 / 13:31–19:00 석식 / 19:01 이후 조식
- 알레르기 정보와 원본 PDF·사진
- 다크 모드, 홈 화면 설치, 오프라인 식단 보기

## 실행

별도의 빌드나 패키지 설치가 필요하지 않습니다.

```sh
python3 -m http.server 8080 --directory dist
```

http://localhost:8080 에서 확인하세요. PWA는 HTTPS 또는 localhost에서 동작합니다.

## 데이터 수정

`dist/menu.json`은 화면에 표시할 식단, `dist/allergies.json`은 원본 PDF에서 옮긴 메뉴별 알레르기 데이터입니다. 필요하면 `python3 build-data.py`로 식단 데이터를 다시 만들 수 있습니다. 페이지나 데이터를 바꾼 뒤에는 다음 명령으로 오프라인 캐시 버전을 갱신하세요.

```sh
python3 build-pwa.py
```

정적 호스팅의 배포 디렉터리는 `dist`입니다. 서비스 워커가 사이트 루트를 사용하므로 루트 경로에 배포하세요.
