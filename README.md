## 주간 식단 갱신

GitHub Actions가 매일 한국 시간 오후 6시에 병무청 메뉴 게시판을 확인해 이번 주와 다음 주 PDF를 내려받습니다. 식단이 변경되면 PDF를 검증해 메뉴 데이터를 생성하고 저장소와 GitHub Pages를 갱신합니다. 게시가 늦어지거나 실행에 실패하면 다음 날 다시 시도합니다. Actions의 **Update and deploy weekly menu**에서 수동 실행할 수도 있습니다.

PDF 형식이 달라져 안전하게 읽을 수 없으면 실행을 실패시키고 기존 식단을 유지합니다. 실행 로그와 원본 PDF를 확인해 `scripts/update-menu.py`의 변환 로직을 수정하세요. 알레르기 정보는 반드시 원본 PDF와 함께 확인해야 합니다.

앱은 현재 주를 기본으로 표시하고, 공개된 다음 주 식단을 선택할 수 있습니다. 온라인에서는 식단 데이터를 갱신하고, 오프라인에서는 마지막으로 저장한 식단을 표시합니다. 원본 PDF는 한 번 열면 오프라인에서도 볼 수 있습니다.
